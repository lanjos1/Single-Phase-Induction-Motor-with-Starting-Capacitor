# Single-Phase Induction Motor with Starting Capacitor

This repository contains a Simulink model and MATLAB scripts for the simulation and dynamic analysis of a **Single-Phase Induction Motor with a Starting Capacitor**. The project evaluates the impact of the auxiliary winding and the starting capacitor on the motor's starting torque and current behavior.

---

## 📌 Project Overview

Single-phase induction motors are widely used in industrial and domestic applications that require high initial torque, such as air compressors, hydraulic pumps, automated gates, and industrial fans. Since single-phase motors cannot inherently generate a rotating magnetic field to start from standstill, an auxiliary winding in series with a **starting capacitor** is used to create the necessary phase shift.

### Objectives:
* Simulate the dynamic behavior of a single-phase asynchronous machine during startup.
* Analyze the transition when the auxiliary winding/capacitor is disconnected (typically at 75% of nominal speed).
* Verify the reduction in total current and stabilization of torque post-startup.

## 🛠️ Specifications & Parameters

Based on the conventional configurations analyzed, the simulation uses the following reference parameters:
* **Starting Capacitor:** $255\ \mu\text{F}$
* **Disconnection Mechanism:** Automatic switch triggered when the rotor reaches approximately **75% of the nominal speed**.
* **Operation Mode:** Continuous operation relies solely on the main winding after the auxiliary circuit opens.

---

## 🚀 How to Run the Simulation

To execute the simulation and plot the performance graphs, follow these steps:

1. **Open Simulink:** Open and run the model file `capacitor_de_partida.slx` to simulate the electrical circuit and motor dynamics.
2. **Run the Post-Processing Script:** Execute the MATLAB Live Script or script `Grafico.mlx` to process the data generated by the simulation.
3. **Analyze Results:** The script will automatically plot the transient responses, including capacitor voltage, electromagnetic torque, and rotor speed over time.

> 💡 **Note:** Both files can be executed using **MATLAB Online** or a local MATLAB/Simulink installation.

---

## 📊 Expected Results

Upon running the simulation, you should observe:
1. **High Starting Torque:** A strong initial torque generated by the temporary rotating magnetic field to overcome rotor inertia.
2. **Current Drop:** A noticeable reduction in total current immediately after the auxiliary winding is disconnected.
3. **Stabilization:** Stabilization of mechanical oscillations as the motor reaches its nominal operational speed.
